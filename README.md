# 🏧 ATM System Simulation

A simple command-line Python application that simulates real-world ATM functionalities. Built to practice core Python concepts like functions, loops, and user input validation.

## ✨ Features
- **User Authentication:** PIN verification logic.
- **Account Operations:** Check current balance, deposit funds, and withdraw money.
- **Input Validation:** Prevents negative deposits or overdrafts.

## 🛠️ Tech Stack
- **Language:** Python 3
